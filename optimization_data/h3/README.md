# H3 数据提取及探索建模

用户于 2026-11-15 确认“盐水不同气泡1”和“盐水不同照片2”两个数据根目录的拍摄高度均为 H3（1.2 m）。本目录保留这条元数据来源；不修改原始索引和照片，也不把共同高度视为相机位置或比例尺一致。

`extract.py` 直接读取既有的 `image_sequence_manifest.csv`，选取两个根目录中已去重且 Q、盐度、PL 完整的记录；原索引缺失 PL 的两组由 `extract_incomplete.py` 单独处理。复用既有 YOLO 适配器，按每张图片保存气泡测量及图片统计，单位 px，支持从 SQLite 成功记录断点续跑。输出独立保存在 `data/h3_confirmed`。

```powershell
conda run --no-capture-output -n BIFBAgent python -X utf8 optimization_data/h3/extract.py --output data/h3_confirmed/full
conda run --no-capture-output -n BIFBAgent python -X utf8 optimization_data/h3/extract_incomplete.py --output data/h3_confirmed/incomplete
conda run --no-capture-output -n BIFBAgent python -X utf8 optimization_data/h3/train.py
conda run --no-capture-output -n BIFBAgent python -X utf8 optimization_data/h3/fit_forest.py
```

`extract_incomplete.py` 对原文件夹未明确标记 PL 的图片单独保存识别结果。用户于 2026-11-15 确认 `Q=1.8,2.5WT%,15%_files` 和 `Q=1.5,2.5WT%,10%_files` 中的 15% 和 10% 是 PL；训练时按此确认使用其既有识别结果，记录 `PL_source`，不修改原始索引。

训练程序要求全部合格图片均已识别成功，缺失或失败时停止。先按来源、Q、盐度及 PL 汇总图片中位径，再等权拟合探索性线性模型；验证时同时留出两个来源中同一 Q/盐度/PL 组合，并与同来源均值基准比较。来源被单独建模，以减少对拍摄位置一致性的假设；跨工况视野和比例尺仍需核实。留出工况评估不等于独立重复实验验证，连续帧也不是独立实验。不能转换为毫米。

输出是独立实验结果；完成后须先检查性能、覆盖与适用范围，才能考虑向 Agent 提供 H3 预测。不同参数组合及来源未必有真实实验对照，不能把训练工况的视觉测量作为独立验证。

本次 H3 数据共有 28,000 张、28 个来源工况，其中 27,963 张含可用的非边缘气泡。以完整 Q/盐度/PL 组合留出、在训练组内五折调参，比较线性模型、同来源均值、RBF 支持向量回归和随机森林。随机森林的 28 工况平均绝对误差约 5.94 px，线性模型约 25.63 px；随机森林现用于探索性界面演示。选择模型与报告对比使用了相同交叉验证结果，仍需要新的独立实验验证。模型、图像统计和评价存于 `data/h3_confirmed/model`。输入扰动结果只是设定扰动的压力测试，不是置信区间。

启动桌面程序后，在运行参数优化页输入高度 H（0.2–1.8 m）、盐度、PL、当前 Q 与目标 Q，并上传当前图片。界面采用 `continuous_height` 独立模型：合并 H1/H2/H3/H4 共 40 个工况、40,000 张图片的既有统计，以 Q、H、盐度、PL 为输入，在留出整个高度时比较线性回归和随机森林；模型选择与展示误差使用了相同验证数据，非独立测试。验证只覆盖盐度 1 wt%、PL 10%；两端高度属于外推。H3 外的盐度与 PL 影响未独立验证；单项范围内但超出已有联合覆盖的组合允许预测，并明确标记为未经验证的组合外推。

跨高度相机视野、裁剪和物理比例尺尚未确认一致；高度与数据来源混杂，模型可能将成像差异学习为高度影响。输出仅供探索、不应视为真实物理趋势。随机森林输出可能呈阶梯状；目标历史 YOLO 数据参与训练，不能视为独立验证。H3 专用模型和 H1/H2/H4 旧模型保留，可由旧接口分别调用。

页面默认目标高度与当前高度相同；勾选“预测其他高度的气泡尺寸”后，可另填目标高度。此时模型分别计算当前 Q / 当前高度与目标 Q / 目标高度；两个输入都改变时，差值同时包含 Q 与高度的影响，不能仅归因于气速。历史目标工况查询也使用目标高度。

当前工况可由拖入的一张原始图片识别，或在页面选择现有工况。图片只用于辅助填写工况；当前大小查询已有逐图片 YOLO 结果，不重新运行识别。每图排除边缘与掩膜边缘未知气泡后求 d50，再对有有效 d50 的图片等权求平均，列出图片数量、低有效气泡数量以及 P10–P90；这些连续帧不是独立重复实验，历史统计不是实时测量。目标 Q、高度、盐度、PL 全部匹配时，页面显示“实际气泡大小（实验照片 YOLO 统计）”及差异；无严格匹配时不显示对比。历史照片曾参与训练，不能作为独立验证。
